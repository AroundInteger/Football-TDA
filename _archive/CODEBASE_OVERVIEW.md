# Football-TDA Codebase Overview

## 📋 Executive Summary

This codebase implements a **groundbreaking research framework** that applies **Topological Data Analysis (TDA)** and **quantum dot physics analogies** to analyze football team dynamics from GPS tracking data. The project is **complete and ready for publication**, with comprehensive documentation, multiple analysis pipelines, and extensive results.

**Key Statistics:**
- **256+ files** total (120 markdown, 62 Python, 56 MATLAB)
- **10,000+ lines of code**
- **100,000+ words of documentation**
- **3 research papers** ready for submission
- **Multiple data sources** integrated (StatsBomb, SkillCorner, SecondSpectrum)

---

## 🏗️ Architecture Overview

### Core Framework: 4-Step Analysis Pipeline

The research follows a systematic 4-step framework:

1. **Step 1: Coupled Collective Variables** - Inter-team dynamics and shape coupling
2. **Step 2: State Space Reconstruction** - Time-delay embedding and attractor identification
3. **Step 3: Zero-Sum Competition & Symmetry Breaking** - Competitive balance analysis
4. **Step 4: Persistent Homology** - Topological feature extraction with quantum insights

### Technology Stack

- **MATLAB R2025a+**: Core analysis framework (8 main classes)
- **Python 3.9+**: TDA computation (ripser, gudhi, teaspoon)
- **Data Formats**: JSON, CSV, MAT files
- **Libraries**: ripser, gudhi, teaspoon, numpy, scipy, pandas, matplotlib

## 🚀 Usage Guide

### Quick Start

1. **Read the README**: Start with `README.md` for overview
2. **Run Complete Pipeline**: Execute `demo_final_integration.m` in MATLAB
3. **Python Analysis**: Run `standalone_step4_analysis.py` for TDA
4. **Explore Results**: Check results directories for outputs

### Key Entry Points

#### MATLAB
```matlab
% Complete analysis pipeline
run('demo_final_integration.m')

% Individual step demos
run('demo_coupled_variables.m')      % Step 1
run('demo_state_space_reconstruction.m')  % Step 2
run('demo_zero_sum_symmetry.m')      % Step 3
run('demo_persistent_homology.m')     % Step 4

% Advanced quantum analysis
run('demo_advanced_quantum_dot.m')
```

#### Python
```bash
# Standalone TDA analysis
python standalone_step4_analysis.py

# StatsBomb analysis
python statsbomb_complete_analysis_pipeline.py

# H1 loop analysis
python analyze_h1_loops.py

# Multi-scale analysis
python multi_scale_temporal_analysis.py
```

### Data Sources

1. **StatsBomb**: Use `open-data/` directory
2. **SkillCorner**: Use `opendata/` directory
3. **SecondSpectrum**: Use `load_secondspectrum_working.m`
