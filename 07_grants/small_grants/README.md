# EPSRC Small Grants Application - Document Structure

This folder contains the complete EPSRC Mathematical Sciences Small Grants application, organised into separate markdown files for easy management and editing.

## File Structure

- **00_Application_Header.md** - Application metadata and basic information
- **01_Application_Summary.md** - 550-word public-facing summary
- **02_Vision_and_Approach - revised.md** - Vision and Approach section (3 pages max)
- **03_Applicant_and_Team_Capability.md** - R4RI team capability section
- **04_References.md** - Bibliography
- **05_Project_Partners.md** - Partner information and contributions
- **06_Resources_and_Costs_R3.md** - Budget breakdown and justification
- **07_Ethics_and_Responsible_Innovation.md** - Ethics and RRI considerations
- **08_Data_Management_Plan.md** - Data management strategy
- **09_Key_Changes.md** - Revision history and changes (for reference)
- **R4RI.md** - Full R4RI with Additions section
- **R4RI M1-4 new.md** - R4RI Modules 1–4 (updated draft)

## Application Details

**Application Type**: Small Grant (Stepping Stone to Standard Grant)  
**Duration**: 12 months  
**Requested Funding**: ~£80,000 (80% of ~£100,000 fEC, subject to institutional costing)  
**Thematic Area**: H. Mathematical Sciences  
**Status**: Revised Draft v4.0 — Post-Validation, Full-Season Focus

**Note on Language**: This application uses **UK English spelling** throughout (e.g., "analyse", "organise", "optimise", "colour", "centre", "realise"). All documents in this folder follow UK English conventions.

- **Budget**: 9-month RA (Months 2–10) within ~£100k fEC (subject to institutional costing)

## Usage

1. Each section can be edited independently
2. Files are numbered for easy reference and ordering
3. The complete application can be assembled by concatenating files in order
4. Individual sections can be exported to PDF as needed for submission
