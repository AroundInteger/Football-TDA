\section{Applicant and team capability to deliver}

\subsection{Contributions to the generation of new ideas, tools, methodologies, or knowledge}

The project lead has demonstrated capacity to develop novel methodological contributions in topological data analysis:

\paragraph{Technical innovations.}
\begin{itemize}
  \item Development of GPS-aware clustering framework resolving $H_0$ artefacts in spatial TDA
  \item Creation of adaptive filtration methods enabling multi-scale $H_1$ detection
  \item Closed cycle identification algorithms for geometric realisation of $H_1$ generators
  \item Temporal persistence landscape methods for dynamical analysis
\end{itemize}

\paragraph{Validated results (11 matches).}
\begin{itemize}
  \item Three $H_0$ analysis regimes with stability scores ${>}0.88$ across all 11 matches
  \item Detection of 5{,}038 $H_1$ loops across 1{,}650 analysis frames with closed cycle geometric realisations
  \item Scale complementarity quantified: Spearman $\rho = 0.25$ between individual and tactical $H_1$ scales
  \item Real event correlation: 104{,}722 event--topology pairs across 10 matches with significant associations
  \item Match-specific temporal dynamics quantified via Wilcoxon rank-sum and permutation tests
  \item Preliminary cross-domain validation on armed conflict event data (Brown et al., in preparation)
\end{itemize}

\paragraph{Software development.}
\begin{itemize}
  \item Comprehensive analysis framework implemented in Python with modular architecture
  \item Open-source implementation planned for community benefit
  \item Integration with established TDA libraries (Ripser, GUDHI, giotto-tda)
  \item Efficient computational methods (${<}2$\,s per frame)
\end{itemize}
