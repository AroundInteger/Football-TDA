## Module 1 - Contributions to the Generation of New Ideas, Tools, Methodologies, or Knowledge

**New ideas and methodologies:**\
This research introduces a multi-scale approach to topological data analysis (TDA), enabling the detection of spatial and temporal patterns in complex systems. These innovations overcome limitations in existing techniques and allow dynamic systems, such as football formations, to be analysed in ways that were previously impractical; opening opportunities for predictive performance modelling.

**Tools and key outputs:**\
The project delivers a computational framework implemented in widely used programming environments, integrating established TDA libraries with novel multi-scale functionality. Designed for efficiency, the framework supports real-time analysis, making it suitable for both research and industry applications. Key outputs include two manuscripts in preparation; one detailing methodological advances for a leading computational topology journal and another presenting applied findings for a broad scientific audience. The work will also generate open-source software and curated datasets to support reproducibility and community engagement.

**Communication of ideas and results:**\
Ideas and results are communicated through planned publications, conference presentations, and open-source releases; ensuring accessibility for both academic and applied communities.

**Skills acquired:**\
Through this research, the team has strengthened expertise in advanced mathematical modelling, computational implementation, and large-scale data processing. These skills, combined with a commitment to open dissemination, ensure that the project contributes not only new knowledge but also practical tools for the wider research community.

## Additions

This section provides context relevant to understanding the team's capacity to deliver the proposed work.

The project builds upon comprehensive preliminary validation of the multi-scale TDA framework across 11 professional football matches (Brown et al., 2026, ArXiv preprint). This validation — including 5,038 H1 loops detected at two complementary scales, real event correlation across 104,722 event–topology pairs, and statistical tests for temporal dynamics — substantially reduces technical risk and demonstrates the project lead's capacity to deliver the proposed objectives. The validated framework provides a strong foundation for the full-season scaling and persistence landscape development proposed in this grant.

Industry partnerships have been established through existing relationships, ensuring data access from the project start. Multiple pathways for enhanced GPS data (Genius Sports, UK; Borussia Dortmund, Germany) provide redundancy, mitigating the primary project risk. These established relationships demonstrate the project lead's capacity to manage complex partnerships and secure necessary resources.

The host institution provides appropriate research environment support, including high-performance computing resources for large-scale TDA computations, data storage facilities for multi-match datasets, and software licences for analysis tools. Institutional support for open science aligns with project objectives and ensures maximum impact.

The project design enables a clear pathway to follow-on funding through a Standard Grant application within 6–8 months of project completion. By generating full-season validation across ~540 matches, developing persistence landscape methods, establishing tactical fingerprinting, and producing peer-reviewed publications, this small grant creates the evidence base for a larger research programme extending the framework to cross-domain competitive systems.
