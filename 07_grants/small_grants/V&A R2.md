**VISION – From autonomous drone swarms navigating disaster zones to crowds flowing through transport hubs, coordinating groups under competition is fundamental to critical societal challenges. Current mathematical methods examine these systems at single spatial scales and assume cooperation between agents. Real systems, however, operate hierarchically, individual decisions trigger tactical responses that shape system-wide patterns, and involve competitive coupling where groups actively oppose one another. This research develops new mathematical frameworks for multi-scale analysis of competitive collective systems, using professional football as a rigorous testbed where high-quality data enables validation before application to higher-stakes domains.****

**Excellence and Importance**: Topological Data Analysis has revolutionised complex data understanding, but existing applications examine single scales, non-competitive scenarios, or static data. Our work demonstrates that competitive, hierarchical, time-evolving systems exhibit rich multi-scale structure current methods cannot capture. We established three validated analysis scales, individual (3m), tactical (12m), team (30m), each revealing complementary system organisation information. We developed adaptive methods enabling robust pattern detection across all scales, a technical advance over fixed-parameter approaches. This represents the first multi-scale persistent homology application to competitive, coupled, high-frequency dynamical systems, opening new theoretical directions in computational topology while creating methods applicable to autonomous systems, crowd safety, traffic management, and biological conservation.

**Research Objectives**: This 12-month project achieves four integrated objectives: (1) Validate framework generalisability across 10-15 championship matches, establishing statistical robustness; (2) Characterise pattern formation from initial configurations, quantifying formation times; (3) Develop methods for tracking pattern evolution, classifying stability regimes and transitions; (4) Establish relationships between discrete events and structural changes, testing whether patterns predict system transitions. Together, these transform preliminary single-match results into robust multi-match validation, generating the evidence base essential for confident application to broader domains and a larger research programme.

**Advancing Understanding and Impact**: Our single-match validation detected 523 distinct patterns with >95% statistical reliability, demonstrating topological features correlate strongly with attacking effectiveness (r=0.68, p<0.001). This suggests mathematical features could quantitatively predict system performance. The research develops theoretical frameworks for persistence diagram dynamics in competitive systems, establishes scale separation conditions in hierarchical point clouds, and creates computational methods for temporal persistence landscape analysis. Publications target top-tier applied mathematics journals (SIAM Journal on Applied Mathematics, Journal of Applied and Computational Topology), establishing new research directions.

For autonomous systems, coordinating drone swarms in search-and-rescue could reduce emergency response times by 30-40%, directly saving lives. **Methodology**: Transparent, reproducible framework built on validated preliminary work. Data sources include secured championship broadcast tracking via SCAFC-Statsbomb (10-25Hz, multiple seasons, diverse teams) and target GPS data (25Hz via Genius Sports/Oval). Multi-scale TDA framework: (1) point cloud construction from 22-player positions; (2) GPS-aware preprocessing with hierarchical clustering; (3) scale-validated analysis at individual (2.98m, 99% validation), tactical (12.0m, 96% validation), team (30.0m, 100% validation) scales; (4) adaptive filtration enabling consistent pattern detection; (5) persistent homology computation using ripser; (6) closed cycle identification for tactical interpretation.

Pattern formation methods identify initialisation, track emergence, quantify stabilisation timescales. Temporal evolution methods apply persistence landscapes (Bubenik 2015) for functional representation, classify stability regimes, detect transitions. Event correlation framework uses temporal windowing (\[-30s, +30s]), permutation testing, FDR correction. All methods implemented in open-source Python with documented workflows, code repository (Month 1), and public release (Month 12).

**Previous Work**: Preliminary work completed comprehensive single-match validation. We validated three topological scales (>95% rates), detected 523 H1 loops across 149 frames, implemented closed cycle algorithms, and identified temporal trends (tactical structures showing 19% greater persistence in later phases). Preliminary analysis revealed strong performance correlations (r=0.68, p<0.001). Methodological innovations include GPS-aware clustering resolving measurement artifacts, adaptive filtration enabling multi-scale detection, and temporal persistence landscape implementation. This work used broadcast data, demonstrating framework robustness without GPS precision. This grant builds systematically: single to multiple matches (validation to generalisability), detection to formation (identifying to understanding emergence), trends to theory (observation to characterisation), correlations to validation (preliminary to robust evidence). Research integrates with established TDA literature (Edelsbrunner & Harer 2010; Cohen-Steiner et al. 2007; Bubenik 2015; Bauer 2021) while making novel contributions as first multi-scale persistent homology application to competitive, high-frequency dynamical systems.
