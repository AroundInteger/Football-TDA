# TDA Framework Visualisation Suite: Usage Guide

## Overview
This document provides a comprehensive guide to the visualisation suite created for the GPS-aware TDA framework. The visualisations are designed for different audiences and use cases, from technical demonstrations to commercial presentations.

## Visualisation Categories

### 1. Technical Visualisations (Academic/Research Audience)

#### `tda_temporal_evolution.png`
**Purpose**: Shows the complete temporal evolution of TDA features across a 90-minute match
**Key Features**:
- H0 and H1 evolution over time
- Complexity index trends
- Quantum state transitions
- Game theory analysis
**Best For**: Academic presentations, technical papers, research demonstrations

#### `tda_epoch_comparison.png`
**Purpose**: Compares analysis across different temporal scales (1min, 2min, 5min, 10min)
**Key Features**:
- Multi-scale H0 and H1 analysis
- Scale-dependent patterns
- Complexity across temporal windows
**Best For**: Methodological validation, multi-scale analysis discussions

#### `tda_formation_analysis.png`
**Purpose**: Demonstrates GPS-aware clustering before and after
**Key Features**:
- Before: H0 artifact (meaningless counting)
- After: Meaningful connected components
- Formation complexity evolution
**Best For**: Technical explanation of the H0 artifact resolution

#### `tda_quantum_states.png`
**Purpose**: Shows quantum phenomena analysis results
**Key Features**:
- Five attractor states with frequencies
- Energy landscapes and band gaps
- Quantum tunnelling transitions
**Best For**: Quantum framework explanation, state identification

#### `tda_game_theory.png`
**Purpose**: Displays game theory integration results
**Key Features**:
- Nash equilibrium discovery
- Zero-sum competitive balance
- p-adic competitive hierarchies
**Best For**: Game theory framework explanation

#### `tda_comprehensive_dashboard.png`
**Purpose**: Complete overview of all framework components
**Key Features**:
- Key metrics summary
- Temporal evolution
- Quantum states
- Nash equilibrium
- Multi-scale analysis
- Framework benefits
**Best For**: Executive summary, comprehensive overview
