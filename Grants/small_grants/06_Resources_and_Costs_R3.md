## Justification of Resources

This section justifies the more costly resources and demonstrates how resources are comprehensive, appropriate, justified, and represent optimal use to achieve intended outcomes and maximise potential impacts.

### Project Staff

**Research Associate (6 months, 100% FTE, Months 4-9, £24,670)**

Essential for achieving all four project objectives within the 12-month timeframe. The 6-month appointment (Months 4-9) concentrates specialist computational effort for setting up concurrent pipeline and analyzing all remaining games from the full Championship season:

- **Objective 1 (Months 4-9)**: RA sets up concurrent processing pipeline and analyzes all remaining games from the 540-match season (~520-525 games, ~77,000-78,000 frame analyses). Processing with persistent homology computation at 3 scales per frame, statistical validation, and quality control. Pipeline architecture enables simultaneous analysis of multiple games, maximising computational efficiency. PI coordinates final analysis incorporating all 540 games (Months 10-12).
- **Objective 2 (Months 4-9)**: Pattern formation method development requiring algorithmic implementation, temporal tracking, and baseline signature identification for ≥3 tactical systems, applied across remaining games during RA period
- **Objective 3 (Month 7)**: Temporal evolution method implementation using persistence landscapes, applied during analysis of remaining games

**Optimal Resource Use**: Preliminary work demonstrated <2s per-frame computational efficiency using institutional Supercomputing Wales cluster (2-Petaflops), enabling concurrent processing of full season. PI analyzes 15-20 initial games (Months 1-3) before RA arrival, establishing validated foundation. RA sets up concurrent processing pipeline (Months 4-5) and executes analysis of all remaining games (Months 6-9). Mature open-source libraries (ripser, GUDHI, giotto-tda) provide robust infrastructure without licensing costs. Phased approach ensures early validation on initial games, intensive specialist effort during RA appointment for analyzing remaining games, with PI coordinating full-season analysis completion incorporating all 540 games (Months 10-12), maximising specialist expertise while enabling cost-effective completion.

**Maximising Outcomes**: Enables achievement of all four research objectives, production of validated reproducible framework, RA career development through co-authorship, code documentation ensuring work continuation, and foundation for Standard Grant application.

**Principal Investigator (165 hours, £8,106)**

Critical for strategic direction and expertise that cannot be delegated: pipeline development and analysis of 15-20 initial games (Months 1-3) before RA arrival, establishing validated foundation; methodology development; RA supervision and training (Months 4-9) while RA sets up pipeline and analyzes remaining games; industry partnership management (crucial for SCAFC-Statsbomb full-season data access); full-season analysis coordination incorporating all 540 games (Months 10-12); event correlation implementation (Months 10-12); manuscript preparation (Months 10-12); and Standard Grant preparation (Months 10-11). 165 hours (average 3.2 hours/week) represents optimal balance, enabling early pipeline validation on initial games, essential oversight during RA appointment for analyzing remaining games, and full-season analysis coordination while maintaining other commitments and leveraging PI's established TDA expertise.

### Resource Optimisation Summary

The requested resources represent optimal use to achieve intended outcomes:

1. **Staff Allocation**: PI analyzes 15-20 initial games (Months 1-3) + 6-month RA sets up pipeline and analyzes remaining games (Months 4-9) + PI coordinates full-season analysis (Months 10-12) + 2 Co-Is (66 hours) ensures comprehensive coverage across computational, theoretical, and domain expertise while maintaining cost-effectiveness for full-season analysis
2. **Infrastructure Leverage**: Utilisation of existing institutional computational and storage infrastructure eliminates need for additional equipment costs
3. **Open-Source Tools**: Primary reliance on mature, free TDA libraries minimises software costs while maximising capability
4. **Focused Investment**: Resources concentrated on essential staff time and directly allocated costs, maximising research quality and impact
5. **Partnership Value**: In-kind data access and expertise from Swansea City AFC provides significant additional value without direct cost

This resource structure ensures all four research objectives are achieved within the 12-month timeline while maximising potential outcomes, impacts, and value for money.
